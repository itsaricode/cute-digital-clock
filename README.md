# 🐱 Cute Interactive Digital Clock ⏰✨

A cute and interactive digital clock built with **HTML, CSS, and JavaScript**.

This project started as a simple digital clock and evolved into a playful UI experience with dynamic themes, animations, and cute cat elements. 🐾

## ✨ Features

* 🕐 Real-time digital clock
* 🎨 Dynamic time-based themes
* 🐱 Cute cat illustrations/elements
* ☕ Different activities and moods throughout the day
* 🌸 Seasonal visual elements
* ✨ CSS animations and transitions
* 🔊 Interactive sound control
* 📱 Clean and responsive interface

## 🎨 Themes

The clock changes its appearance according to different parts of the day, creating a more dynamic experience instead of displaying only the current time.

Examples include:

* ☕ Breakfast Time
* 🧹 Cleaning Time
* 📚 Study Time
* 💻 Relax / TV Time
* 🍽️ Dinner Time
* Sleep Time

## 🛠️ Built With

* **HTML5** — structure
* **CSS3** — styling, animations & transitions
* **JavaScript** — clock logic, theme switching & interactions

## 🚀 How to Run

1. Clone this repository:


(https://github.com/itsaricode/cute-digital-clock.git)


2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
